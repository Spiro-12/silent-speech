# Code of conduct

Be kind, be patient, assume good intent. No harassment, insults or personal attacks, in issues, pull requests or
anywhere else in this project.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
If something goes wrong, report it privately through the repo's **Security** tab (Report a vulnerability works for
conduct reports too) and the maintainer will handle it.
